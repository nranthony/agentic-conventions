🗂 Provenance — the durable “why”

Spans docs/, work/, and conventions/: decisions, the proposals on their way to becoming one, and cross-repo registries.

  • docs/adr/ — append-only decisions (0001–0007) + 0000-template.md
  • work/NNNN-slug/ — numbered proposals & in-flight items (proposal → spec → plan → notes)
  • work/archive/ — resolved items, distilled first; historical, never current intent
  • docs/distributing-skills-downstream.md — consumer guidance
  • conventions/beads/ — ADOPTION.md (rollout) · PREFIXES.md · VERSION.md

♻️ Ephemeral — gitignored, never committed

Working material with a built-in exit; structurally unable to go stale in the tree.

  • inbox/ — paste-in material → distill into a doc/ADR → delete
  • work/plans/ — native plan-mode drafts → promote to work/NNNN-slug/
  • AGENTS.local.md — personal context, imported if present
  • .claude/settings.local.json — personal setting overrides

How an idea becomes convention

inbox/raw notes, pasted docs
→
work/NNNN-slug/proposal.md under discussion
→
docs/adr/decision recorded, append-only
→
reference + templatesblueprint & mirrors updated
→
downstream repos/plugin install, or host-seeded into a profile

Skills travel the same road: live in .claude/skills/, genericised into templates/.claude/skills/, then vendored into a consumer (or seeded into a container’s ~/.claude per instance) — content travels, personal paths never do.

Decisions so far

ADR-0001 Accepted Reference, not automation — no scaffolder; an agent applies conventions with judgment.
ADR-0002 Superseded Slash commands for human-invoked procedures — folded into skills by ADR-0004.
ADR-0003 Accepted Plans live in work/ (exit rule); execution tracking in beads where adopted.
ADR-0004 Accepted Skills replace commands: one slot, /name + auto-trigger, simpler distribution.
ADR-0005 Superseded Proposals live in docs/rfcs/ — retired the *_PLAN.md pattern; folded into work items by ADR-0006.
ADR-0006 Accepted Proposals are work/NNNN-slug/ items — one numbered pipeline; distill to an ADR, then archive. docs/rfcs/ retired.
ADR-0007 Accepted Distribute as a Claude Code plugin (myconv): marketplace for networked machines, host-seeded @skills-dir for closed-egress profiles.
